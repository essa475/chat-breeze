# Chat Breeze

Chat Ebola — Full Chat App

Build a complete Chat Ebola messaging application.

Technology

Use any language/framework/database supported by the builder/platform. Do not force PHP + MySQL. Choose the best built-in technology so the app actually works and can be deployed easily.

1. Landing Page

- Big Chat Ebola hero with tagline, Get Started and Explore buttons.

- Feature cards with app screenshots that tilt in 3D on mouse movement.

- Smooth scrolling features, how-it-works and footer sections.

- Buttons go to login.

2. Login & Signup

- Login with email or phone + password.

- If account doesn't exist, continue to signup:

  1. Email/phone + password

  2. First name, last name, username with live uniqueness check

  3. Date of birth with automatic age calculation

  4. Profile photo + bio, both optional, with Skip button

- Secure password hashing and persistent authentication/session.

3. Chat Interface

- Empty state for new users with search prompt.

- Search by username, email, name or phone.

- Results show photo, name, bio, Add to chat and Message.

- Privacy mode can require a request before messaging.

- Requests inbox with accept/decline.

4. Messages

- Text + attachments: images, video, documents, Excel, ZIP and other file types.

- Maximum 50 MB per file.

- Images/videos preview inline; other files show icon, name, size and download.

- Messages show time and sent/delivered/read receipts.

- Read receipt is the only colored accent.

- New messages update automatically without page refresh.

5. Long-Press Menu

On own messages:

- Copy

- Edit

- Reply

- React with emoji

- Delete for me

- Delete for everyone

On other messages:

- Copy

- React

- Reply

- Delete for me

Works with long-press on mobile and right-click on desktop.

6. Groups

- Create group with name and photo.

- Add/remove members.

- Promote/demote admins.

- Leave group.

- Rename group.

- Change group photo.

- Admin-only actions hidden from regular members.

7. Settings

- Privacy toggle: require request before messaging.

- Edit profile.

- Change photo/bio.

- Logout.

Technical Requirements

- Use the platform's best-supported backend and database.

- Persistent user, chat, message, request, group, reaction, attachment and read-receipt data.

- Secure authentication, authorization, validation and file handling.

- Attachments up to 50 MB.

- Responsive on mobile, tablet and PC.

- Clean white/black/gray/light-gray design.

- Smooth modern UI animations.

- No fake/demo-only features.

- Provide setup/deployment instructions appropriate to the chosen technology.
